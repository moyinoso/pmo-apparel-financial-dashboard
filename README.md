# PMO's Apparel Financial Performance Dashboard

## Project Overview

This project presents an interactive financial performance dashboard
developed in Microsoft Excel for PMO's Apparel.

The dashboard analyses revenue, expenses and profit across monthly,
product and yearly dimensions, with interactive slicers for filtering
the analysis.

## Business Questions

The analysis was designed to answer:

- What is the overall financial performance of the business?
- How do revenue, expenses and profit change across months?
- Which products contribute the most revenue?
- How did financial performance change between 2024 and 2025?
- What periods show the strongest financial performance?

## Dashboard Features

- Revenue KPI
- Expenses KPI
- Profit KPI
- Profit Margin KPI
- Monthly Revenue, Expenses & Profit analysis
- Revenue by Product
- 2024 vs 2025 Performance comparison
- Month slicer
- Product slicer
- Key business insights

## Key Findings

- Total revenue was approximately ₦2.43B.
- Total profit was approximately ₦1.23B.
- Overall profit margin was 50.50%.
- Zen T-Shirt was the largest product revenue contributor at approximately ₦1.52B.
- August was the strongest month, generating approximately ₦333.3M in revenue and ₦164.0M in profit.
- 2025 generated higher profit despite lower revenue compared with 2024, driven by lower expenses.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas
- Data cleaning
- Data visualization

## Data Quality Note

Some records contained blank Date values. These records were retained
because they contained valid financial information. For the monthly
analysis, the blank-date category was excluded from the PivotTable
visual so that the monthly chart reflected identifiable January–December
performance.

## Project Outcome

The dashboard transforms the underlying financial data into an
interactive management reporting tool that allows users to examine
financial performance by month, product and year.
